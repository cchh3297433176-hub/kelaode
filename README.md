# 世界书管理器

酒馆世界书管理器二改。2.6.0 增加世界书配套正则。

## 使用

1. 打开世界书管理器，选择一本世界书，点击书名旁的 `</>` 图标。
2. 新建正则、导入正则 JSON，或从已有全局、预设、角色正则中复制。复制不会删除原件；同一规则的原件和配套副本都开启时可能重复处理，请自行停用不需要的一份。
3. 启用这本世界书后，配套正则自动生效。停用后撤下运行副本，世界书内的配置保留。
4. 在酒馆的“正则 → 世界书正则”分区查看当前已启用的世界书；每本书可折叠，规则可开关或编辑。普通全局列表不重复显示这些副本。
5. 用管理器导出世界书 JSON，即可携带正则及其他扩展数据。TXT 导出仍为纯文本，不携带正则。

支持全局、当前角色主/辅助世界书、聊天世界书和人设世界书。一本书从多个来源启用只加载一次。“启用”指当前上下文已绑定该世界书，不要求某个关键词条目命中。正则自身的作用位置、显示/发送选项、深度等仍然生效。

## 数据与兼容性

- 原件存放于世界书 `extensions.kelaode_worldbook_regex`，包含 `version: 1` 和 `regexes` 数组，不作为世界书条目发送给 AI。
- 执行时复用酒馆原生引擎；运行副本的 ID 以 `kelaode-wbr:` 开头，并记录来源世界书。仅这些副本会被自动清理。
- 管理器启动、世界书/角色/聊天切换、设置变更及生成前会同步。同步失败时撤下旧副本并显示错误，不沿用旧聊天的正则。
- 可在配套正则管理器中调整规则顺序。不同世界书的配套规则按当前绑定来源的读取顺序执行，并位于普通全局规则之后。
- 世界书正则需要本插件才能自动加载；没有插件时，世界书条目仍可正常使用。
- 其他第三方正则管理器仍可能看到这些底层全局副本；本插件只负责原生面板的独立展示，不隐藏其他插件的界面。
- 酒馆保存全局设置时，可能一并保存运行副本。本插件下次启动会清理并重建。**卸载或禁用本插件前，请先在“世界书正则”分区取消“启用联动”**，清理副本并保存设置；世界书文件中的原件会保留。

## 开发验证

无需安装项目依赖：

```sh
node --experimental-vm-modules --test tests/worldbook-regex.test.mjs
```

可选的手机浏览器交互测试（需要 Playwright 和 Chromium）：

```sh
node tests/worldbook-regex.browser.cjs
# 使用已有浏览器时可设置 WBR_BROWSER_PATH=/path/to/chromium
```

测试覆盖文件携带、选项保留、无效文件、重复绑定、异步切换、失败清理和人设绑定。测试通过不代表已在所有酒馆版本、主题和第三方插件组合上实机验证。
