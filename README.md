# 世界书管理器

酒馆世界书管理器二改，按 SillyTavern 1.18 的世界书加载接口实现。

## 随机组

在一本世界书的「条目」页点骰子图标，勾选至少两条候选，设置「每轮抽取」的条数，再创建随机组。已存在的组也能改数量。所选条目设为蓝灯，通用格式和总控可以留在组外。

可以给随机组填写显示名。勾选「轮完再抽」后，当前聊天里已经抽过的条目要等其他候选轮完才会再次抽到。当前轮剩余条目凑不满时，先抽完剩余条目，再从下一轮补足，同次抽取仍然去重。每个组独立抽取和计数，可以在同一次生成中各出一条。实际通过酒馆世界书预算并激活的条目才计入进度，「试抽」只预览。本轮进度保存在聊天里，随机组设置随世界书 JSON 导出。

旧组默认抽一条，由酒馆原生包含组选取。抽多条时，管理器从本轮启用的组成员中按权重抽取，同轮不重复，候选不足时只抽可用条数。移出的成员会停用，可在条目页重新开启。包含概率、时效等高级触发设置的组继续走酒馆原生逻辑。

## 悬浮球与条目快照

- 「管理世界书」底部的「悬浮球设置」可开关悬浮球、调节大小、导入 PNG / GIF / JPG / WebP 等浏览器支持的图片、选择快捷世界书。球出现在酒馆原有聊天页，球内的齿轮也能打开同一设置。自定义图片保存在导入它的浏览器中。
- 自定义图片按原始比例无框显示。轻点悬浮球打开菜单，按住直接拖动可以挪到输入框上方的任意位置。松手后记住位置，刷新页面或旋转屏幕时按当前聊天区域重新定位。
- 快捷菜单和设置里的选书列表都能按已有标签筛选。主要世界书默认隐藏，点「显示主书」可查看，筛选只改变列表显示。
- 在球内用带「开／关」字样的滑块开关一本书，仅作用于当前聊天，并同步启停该书的配套正则。切回符合原绑定状态的开关会撤销该聊天的临时覆盖。
- 「条目」页的「条目快照」和球内每本书的叠层按钮可打开快照。调整条目开关并命名保存，点快照名称即可应用到当前聊天，点「原书条目设置」即可恢复。快照随世界书 JSON 导出，应用时会按条目身份匹配，新增或无法匹配的条目沿用原设置。
- 在「条目快照」勾选「存为条目分组」，用「纳入」挑选成员，并设置成员的开关。应用分组只修改当前聊天里收录条目的开关。条目可同时属于多组，分组随世界书 JSON 导出。

## 使用

1. 打开世界书管理器，选择一本世界书，切换到书名下方的“配套正则”页签。
2. 新建正则、导入正则 JSON，或从全局、当前预设或当前角色卡移动已有正则。确认移动后，管理器先保存世界书，再从原位置移除正则。
3. 启用这本世界书后，配套正则自动生效。停用后撤下运行副本，世界书内的配置保留。
4. 在酒馆的“正则 → 世界书正则”分区查看当前已启用的世界书；每本书可折叠，规则可开关或编辑。普通全局列表不重复显示这些副本。
5. 用「连同正则导出」生成带绑定的 JSON，用管理器导入即可恢复。只需要条目时选「仅导出世界书」。TXT 导出仍为纯文本，不携带正则。
6. 用「更新已有世界书」按书名或标签选择目标和新版文件。默认只替换条目，带正则的文件可勾选同时替换绑定。

支持全局、当前角色主/辅助世界书、聊天世界书和人设世界书。一本书从多个来源启用只加载一次。“启用”指当前上下文已绑定该世界书，不要求某个关键词条目命中。正则自身的作用位置、显示/发送选项、深度等仍然生效。

## 状态栏生成器联动

同时更新“序白 · 状态栏生成器”至 3.8.4 或以上。在生成器的“保存到”选择“世界书”，筛选并选择目标后绑定。默认只展示全局已开启的世界书，始终排除当前角色的主要世界书；可取消全局筛选并使用名称关键词搜索。

配套显示规则和勾选的发送过滤规则一起保存到所选世界书，不额外保存一份普通全局正则，也不会自动开启目标世界书。目标选择只读取名称与绑定状态，不会自动把世界书内容发送给生成器的 AI。

## 数据与兼容性

- 原件存放于世界书 `extensions.kelaode_worldbook_regex`，包含 `version: 1` 和 `regexes` 数组，不作为世界书条目发送给 AI。
- 执行时复用酒馆原生引擎；运行副本的 ID 以 `kelaode-wbr:` 开头，并记录来源世界书。仅这些副本会被自动清理。
- 管理器启动、世界书/角色/聊天切换、设置变更及生成前会同步。同步失败时撤下旧副本并显示错误，不沿用旧聊天的正则。
- 可在配套正则管理器中调整规则顺序。不同世界书的配套规则按当前绑定来源的读取顺序执行，并位于普通全局规则之后。
- 世界书正则需要本插件才能自动加载；没有插件时，世界书条目仍可正常使用。
- 其他第三方正则管理器仍可能看到这些底层全局副本；本插件只负责原生面板的独立展示，不隐藏其他插件的界面。
- 酒馆保存全局设置时，可能一并保存运行副本。本插件下次启动会清理并重建。**卸载或禁用本插件前，请先在“世界书正则”分区取消“启用联动”**，清理副本并保存设置；世界书文件中的原件会保留。

## 开发验证

无需安装项目依赖：

```sh
node --experimental-vm-modules --test tests/*.test.mjs
```

可选的手机浏览器交互测试（需要 Playwright 和 Chromium）：

```sh
node tests/worldbook-regex.browser.cjs
# 跨插件测试：设置 XUBAI_STATUSBAR_REPO_PATH 为生成器仓库的本地路径
# 使用已有浏览器时可设置 WBR_BROWSER_PATH=/path/to/chromium
```

测试覆盖文件携带、选项保留、无效文件、重复绑定、异步切换、失败清理、人设绑定及生成器绑定。浏览器测试包含原生折叠层级、超长书名、内嵌编辑页签，以及可选的跨插件保存流程。测试通过不代表已在所有酒馆版本、主题和第三方插件组合上实机验证。
